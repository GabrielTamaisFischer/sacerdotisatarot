# A Sacerdotisa Tarot

Site institucional desenvolvido para **Sandra**, profissional especializada em Tarot, com o objetivo de apresentar seu trabalho, divulgar seus serviços e facilitar o agendamento de consultas.

O projeto transforma a presença profissional da cliente em uma experiência digital moderna, responsiva e alinhada à identidade mística do seu trabalho.

## Sobre o projeto

A plataforma reúne informações sobre as especialidades da Sandra, explica as modalidades de atendimento e conduz o visitante até o contato direto pelo WhatsApp.

O design utiliza uma estética mística com tons de roxo, dourado e preto, elementos astrológicos, animações e transições para criar uma navegação envolvente sem perder a clareza das informações.

## Principais recursos

- Apresentação profissional da taróloga
- Conteúdo sobre Tarot Rider-Waite
- Conteúdo sobre Baralho Lenormand
- Seção interativa com os signos do zodíaco
- Exibição das opções e valores de consulta
- Agendamento direto pelo WhatsApp
- Informações de contato e horários de atendimento
- Links para redes sociais
- Layout responsivo para computadores, tablets e celulares
- Animações e efeitos visuais durante a navegação

## Tecnologias utilizadas

- **Next.js 15**
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **Radix UI**
- **Lucide React**
- **Vercel**

## Como executar localmente

### Pré-requisitos

- Node.js 22 ou superior
- npm

### Instalação

```bash
git clone https://github.com/GabrielTamaisFischer/sacerdotisatarot.git
cd sacerdotisatarot
npm install
npm run dev
```

Depois, acesse [http://localhost:3000](http://localhost:3000) no navegador.

## Objetivo

Este site foi criado para uma cliente que precisava divulgar seu trabalho com Tarot de maneira profissional, transmitir confiança ao público e tornar o contato para novas consultas mais rápido e acessível.
